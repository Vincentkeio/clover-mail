补齐全新安装的空间清理，保护同机其他项目的数据和缓存。

- 一键安装和 Compose 初始化均使用本次安装独立创建的构建器；构建成功或失败后，自动移除该构建器及其缓存卷。
- 下载源码的临时文件在启动安装器前清理；临时邮件证书使用独立目录，安装结束或出错时回收。
- 全新安装不再误触发更新前的镜像记录流程。已有版本更新的备份与清理流程保持原有安全边界。
- 不扫描删除其他镜像，不清理共享构建缓存，不删除业务数据卷；运行所需的服务镜像及共享构建工具镜像保留。

全新安装需要支持独立构建器的 Docker Buildx 和 Compose。缺少支持时明确停止，不回退到会积累共享缓存的构建方式。若 Docker 拒绝移除本次构建器，将提示重试命令并报告失败。
