安全修复，改进邮件权限、账户管理和备份保护。

- 关闭全局 SMTP 或停用邮箱后，465/587 端口也会阻止对应邮箱提交邮件；设置在邮件服务重启后继续生效。
- 重置管理员密码后，旧面板会话失效，同时保留 Cloudflare Token 和 Webmail 凭据的解密能力。
- 登录增加尝试次数限制，操作过于频繁时显示重试提示。
- 邮箱密码修改或删除失败时明确报告失败，删除失败的邮箱继续保留在面板中，便于重试。
- 日志与错误信息过滤密码、Token、认证头和私钥；敏感下载禁止缓存，备份文件默认仅所有者可读写。
- 反垃圾管理端口仅绑定本机，不再通过公共 Web 入口直接访问。
- 更新存在已知安全告警的生产依赖，发布镜像前增加安全回归检查。

更新后需要重新登录面板。
