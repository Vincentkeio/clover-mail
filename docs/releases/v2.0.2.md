新增备份导入恢复和独立的一键迁移模块，方便将 Clover 配置与持久数据迁移到新 VPS。

- 面板数据库和邮件配置均支持下载、导入与恢复。
- 备份按钮附近明确提示：单项备份不含邮件正文、Roundcube 通讯录及偏好数据。
- 一键迁移支持导出加密迁移包，并在目标实例导入恢复，覆盖面板数据库、邮件正文、邮件服务账号及转发配置、Roundcube 通讯录与偏好、证书状态和项目部署配置。
- 恢复前校验迁移口令和文件内容，要求输入 `RESTORE` 确认覆盖；恢复过程中显示任务状态，并保留服务器任务日志。
- 保留邮件数据的文件所有者和权限，适配目标 VPS 项目目录，并提供完整迁移示例。

迁移前请在目标 VPS 安装相同版本的 Clover。导出期间邮件与 WebMail 会短暂停止；恢复会覆盖目标实例数据并重启服务。迁移完成后仍需检查公网 IP、DNS、PTR、防火墙及证书；迁移包不包含 VPS 系统级配置或提供商侧设置。
