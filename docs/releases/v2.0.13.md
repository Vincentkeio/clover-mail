修复反向代理部署下无法登录面板的问题，并加固接口的来源校验。

- 修复使用宿主机 nginx 或 Caddy 共享入口时，面板始终提示“用户名或密码错误”的问题。此前面板从转发头推断访问协议，在代理层终止 TLS 时会得到 `http://`，与浏览器实际使用的 `https://` 不一致，登录请求被拒绝；现在改为按配置的面板地址校验，安装与升级时自动补全。
- 登录失败时如果原因是面板地址不匹配，会直接说明，不再统一显示为用户名或密码错误。
- 加固来源校验：拒绝同站不同源的子资源请求，不再因为请求缺少 `Origin` 头就直接放行。地址栏访问、页面内正常操作、命令行与定时任务均不受影响。
- 修复在尚未添加任何转发规则时，账号对账始终失败的问题；此时邮箱与转发规则的差异现在能正常检出。
